# レースのブレを切り分けるノウハウ

Blackboxを開いて、問題の局面を見つけ、仮説を一つずつ試し、再フライトで確かめるための文書集です。
2026-11-13までの実ログ調査と、PIDtoolbox・UAV Techの公開解説から得た知見を整理しました。

**目的は、グラフを綺麗にすることではなく、普段のレース操作で狙ったラインを保てるようにすることです。**

## 基本姿勢

- 観測、原因仮説、変更案、実際の改善確認を分けます。
- モーターの指令上限と実測推力、RPM変動とモーター故障を同一視しません。
- 入力・負荷・電圧の違いを、PID変更の効果として扱いません。
- データ不足による判断保留と、評価した範囲で追加変更不要な状態を分けます。
- 原本を保存し、欠測や非対応の信号を都合よく補いません。

## 公開範囲

この文書集は、一般化した検証手順、特定ログでの集計結果、参照資料を公開するものです。
生BBL、DVR、字幕全文、個体識別情報、ローカル素材へのリンク、調査用実行環境は含めません。
実例の生データを配布しないため、第三者がその数値を独立に再計算できる再現データセットではありません。

また、汎用Autotune・AI診断・自動CLI生成を実装済みとする文書ではありません。
特定のPID値やフィルター設定を他機体へ適用する手順でもありません。
原典の有効範囲と、対象FW・機体・実際のフライト条件を確認して利用してください。
