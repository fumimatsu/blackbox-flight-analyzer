# AirMode ONのターンで見つかったブレ

[文書集の入口](README.md)

2026-11-13までの調査を、個別素材や作業環境に依存しない形でまとめた事例です。
対象は5.1インチ機の2本のAirMode ONフライト。記録FWはBetaflight 2026.6.2、normal resolution、
記録周期中央値は約499us（約2004Hz）。設定上のgyro/PID周期とログ周期は別に扱いました。
以下の秒はDVR換算の目安で、生のBBL時刻ではありません。

生データは公開していないため、第三者がこの表を独立に再計算できる資料ではありません。
他機体向けの判定閾値や推奨設定を得た研究でもありません。

## 1. 最初に確認した症状

4本目のDVRの38.85秒付近について、見た目のブレと調べたい箇所が一致するとユーザーが確認しました。
ログには、滑らかなRoll要求に対して、要求にない約31〜35Hzの往復がありました。
主なバーストは約150ms、4〜5周期程度の短い現象です。

電圧低下、モーター指令上下限、P/Dの大きな動きも重なりました。
一方、収束後にも高スロットルと上限側のmotor指令が残ったため、
「高スロットルだけ」「motor上限だけ」「電圧低下だけ」を十分な原因説明にはしませんでした。

## 2. フィルター遅れを比較した結果

各0.5秒の窓で、記録されたgyro前後の約31Hzでの位相差を比較しました。
前後の安定側はこの帯域の信号が弱く、計算法を変えると推定値にも幅がありました。

| DVR換算区間 | Roll誤差8〜40Hz RMS | gyro前→後の位相差のms換算 |
|---|---:|---:|
| 前37.90〜38.40秒 | 8.22°/s | 約1.19ms |
| ブレ38.60〜39.10秒 | 81.70°/s | 約1.43ms |
| 後39.20〜39.70秒 | 3.14°/s | 約1.80ms |

位相のms換算は、一定の処理遅延や群遅延ではありません。
**ブレ中だけ遅れが異常に増えたという根拠は得られませんでした。**
ただし、元々ある処理の遅れが負荷・外乱・出力制限と組み合わさって寄与する可能性は残ります。

D経路は負の微分の位相を除いて確認しましたが、実TPA・動的カットオフは未記録です。
この結果だけでフィルター解除・D増加を選ばず、フィルター変更は保留しました。

## 3. 他のONターンにも出ていたか

| DVR | 換算時刻 | Roll誤差8〜40Hz RMS | 主な周波数ビン |
|---|---:|---:|---:|
| 3本目 | 50.70秒 | 48.9°/s | 約31Hz |
| 4本目 | 36.17秒 | 35.8°/s | 約31Hz |
| 4本目 | 38.85秒 | 81.7°/s | 約31Hz |
| 4本目 | 61.11秒 | 82.1°/s | 約27Hz |
| 4本目 | 69.32秒 | 96.4°/s | 約27Hz |

これらはログ上の類似振動です。他の箇所の見た目が同じことや、原因が同じことまでは確認していません。
主ビンの刻みは約3.91Hzであり、精密な共振周波数の同定ではありません。

先頭・末尾、gyro飽和近傍、欠測等を除外し、重なる候補窓を統合すると、2本で21候補群が残りました。
これは21個の独立したターンや21回の故障という意味ではありません。
別枠の高誤差6群も残し、抽出条件に合わないから正常と判断することは避けました。
例えば3本目78.55秒の大きな偏りは、主ビン約12Hzの単発的な乱れで、31Hz型とは分けています。

## 4. どの条件と重なったか

今回の候補のうち、記述用にRMS40°/s以上と区切った11群では、
いずれも前0.3秒と対象窓を合わせた範囲内に、150msで30ポイント以上のRCスロットル増分がありました。
40や30は、この事例の集計上の境界であり、他機体の良否を決める値ではありません。
増分には振動中の操作も含むため、先行する原因だけを測ったものではありません。

小さい候補には急な開け直しを伴わない例もあり、急な開け直しは必要条件ではありません。
また、同程度の開け直しでも安定している窓があり、それだけで発生を説明できません。

現在の要求・RC・電圧・入力波形を近づけ、周辺の高誤差も避けた比較は10組成立しました。
候補側は対照側より開け直し増分、motor上下限、電圧変動が大きい傾向でしたが、
速度・ライン・空力・パック等は揃っておらず、因果効果の推定ではありません。
P、motor制限、電圧変動は、振動の結果として増えている可能性もあります。

## 5. 38.85秒の参考対照と、比較の限界

4本目73.624秒の窓は、現在の入力・電圧は近く、往復振動は小さい区間でした。
ただし直前に別の追従誤差があるため、履歴まで静かな対照を要求する厳格条件では不成立です。
以下は同条件のA/Bではなく、現在値の近い参考例です。

| 値 | 38.85秒 | 73.624秒（参考例） |
|---|---:|---:|
| RCスロットル中央値 | 86.1% | 82.1% |
| 電圧中央値 | 20.39V | 20.41V |
| 誤差8〜40Hz RMS | 81.70°/s | 2.29°/s |
| いずれかのmotor指令が99.5%以上のフレーム比 | 76.7% | 37.5% |
| いずれかのmotor指令が1%以下のフレーム比 | 3.8% | 0% |
| 窓内最低電圧 | 19.22V | 20.21V |

高RCや20V台という値だけでは、ブレの有無を十分に説明できない参考例です。
motor上下限の比率は各0.5秒窓のフレーム数を分母とする集計です。
指令の制限付近に達した割合であり、実推力や故障の測定ではありません。
電圧差から電池劣化や内部抵抗を確定することもできません。

## 6. 結論と次の試験

今回の候補ではI上限への張り付きや、D Maxの大幅増強は共通条件になりませんでした。
実TPAは未記録で、TPA前の係数と実際に作用したDの条件を完全には分離できません。
P過大、実効D不足、空力外乱、電源・機械条件のどれかへ原因を確定していません。

次はAirMode ONと制御・フィルター設定を固定し、同じターンの開け直し方と、
識別したパックでの再現性を確認する方針です。可能なら実TPAも直接記録します。
滑らかに操縦して静かになったことを最終成功とせず、普段のレース操作での改善と副作用を確かめます。
