# DejaView連携・空間フライトレビュー WBS

更新日: 2026-10-22

## 到達点

同一フライトのDejaView推定軌跡・DVR・Blackboxを同期し、1コーナーの操作と機体反応を空間上で確認する。
最初の実証は保存結果によるオフラインレビューとする。

## 分担と既存資産

- `fumimatsu/dejaview` / `E:/src/dejaview`: 自己位置推定の正本。
- 本リポジトリ: Blackboxの読み取り、DVR同期、操作・機体反応の分析。
- `E:/3DGS/virtual-momo-fpvrc`: 既存Unity表示。連携先の候補。
- DejaViewの `replay.json` / `frames.jsonl` と保存再生、`aso-pose/v1`、`presentation-v2` を調査して再利用する。
- `observed / provisional / predicted / lost`、地図・校正・モデルの識別を連携時にも維持する。
- 地図の `metersPerSourceUnit` は実寸を検証してから距離・速度の分析に使う。

参照: DejaViewの `docs/INTEGRATION.md`、`docs/ASO_C_LIVE_CODEX_HANDOFF.md`、`tools/course_localization/experience_broadcast_replay.py`。
本WBSではDejaView側のコードや通信契約を変更しない。必要になった場合は影響を確認して別タスク化する。
